database Database Architecture

Supabase Cloud Database Schema & Policies

🗄️ public.photos
Stores complete photo metadata: id, title, category, url, date_added, rating, is_favorite, is_trashed, album, user_id, uploader_name, size.
🗄️ public.profiles
User accounts: id, username, email, name, role, avatar_color, bio, and timestamps.
🗄️ public.categories
Category registry: id, name (unique). Pre-seeded with Nature, Travel, Architecture, Abstract, Portraits, and My Uploads.
🗄️ storage.buckets ('photos')
Public bucket storing original image files with 50MB file size limit and strict image MIME verification.
